# Отчёт о реализации — Каталог функций Фонда

> Дата: сентябрь 2026  
> Версия: 1.1 (демо / PoC)  
> Стек: React 19 + Vite 8 + bpmn-js 17 + CSS Modules  
> Архитектура: Feature-Sliced Design (FSD)  
> Расположение: `documentation/` (не `docs/` — эта папка очищается при `npm run build`)

---

## 1. Общее описание

Реализован фронтенд-демо **«Каталог функций Фонда»** на основе ТЗ «на разработку и внедрение автоматизированного Каталога функций Фонда на ВКП».

Проект демонстрирует полный пользовательский сценарий каталога — от главной страницы с направлениями деятельности до карточки конкретной функции с BPMN-схемой, таблицей подфункций и блоком ВНД. Данные хранятся в localStorage (имитация API).

## 4. Маршрутизация

| Маршрут | Страница | Описание |
|---|---|---|
| `#/` | CatalogMainPage | Главная: поиск + фильтры + 7 карточек направлений |
| `#/direction/:id` | DirectionPage | Breadcrumbs + таблица функций 1-го уровня |
| `#/function/:id` | FunctionCardPage | Карточка функции: BPMN + L2 таблица + ВНД + информация + история |

## 8. Известные ограничения

1. **Данные в localStorage** — при очистке данных браузера все изменения теряются. Версионирование mock-данных обеспечивает автоматический сброс при обновлении версии.
2. **Авторизация клиентская** — переключатель ролей в Header без серверной проверки.
3. **BPMN-схема по умолчанию** — в mock-данных 9 функций используют одну демо-схему «Обработка заявки»; администратор может загрузить свою.
4. **Ссылки ВНД** — ведут на `#` (заглушки), т.к. Базы знаний нет в demo.
5. **Старые страницы** — ViewerPage и EditorPage (standalone BPMN демо) остались в коде, но не подключены к роутингу.
